## 物质效果分类参考

一个面向中文用户的药物/精神活性物质**体验报告博物馆**式参考站。数据来自
[Erowid Experience Vaults](https://erowid.org/experiences/)（体验报告库），
经本地 NLLB-200-3.3B（CTranslate2）英译中后整理发布。

> ⚠️ **本站为教育与研究用途的资料整理，不提供任何使用建议、不构成医疗意见。**
> 内容仅客观呈现他人经验报告中的主观体验与已知危害信息。

## 内容组织

- **九大药理分类**（按作用机制与效应谱）：
  致幻剂 · 解离剂 · 兴奋剂 · 阿片类 · 抑制剂 · 大麻素 · 抗胆碱能类 · 吸入剂 · 综合/未指明
- **880 个物质页**：每个物质含药理类别、三量表（生理作用 / 心理作用 / 生理危害，各 1–5 级）
  以及来自报告综述的效应描述
- **5200+ 篇报告页**：机器翻译正文 + 折叠的英文原文，附剂量 / 给药途径 / 日期元数据
